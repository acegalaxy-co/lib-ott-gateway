# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

Be respectful. Assume good faith. No harassment, no personal attacks, no discrimination.

We're a small project and we want to keep it pleasant to work in.

## Enforcement

Report violations to **conduct@acegalaxy.co**. Reports are confidential.
Maintainers will respond within 7 days and may warn, temp-ban, or perma-ban
contributors as needed.

## Scope

Applies to all project spaces: GitHub issues/PRs/discussions, and any
official chat channels.
